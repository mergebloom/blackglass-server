# Project instructions

- Do not create or switch Git branches unless the user explicitly asks.
- Never modify the installed Obsidian application or a real user vault from project scripts.
- Reference release artifacts are read-only inputs and must not be committed.
- Default all integration tests to temporary directories and loopback network interfaces.
- Client transformations must be deterministic, fail closed, and record the upstream artifact hash.
- Do not weaken TLS or authentication for non-loopback deployments.
